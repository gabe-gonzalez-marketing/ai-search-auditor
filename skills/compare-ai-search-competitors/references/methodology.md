# Comparison methodology

All sites receive the same page cap, request delay, timeout, evidence rules, and scoring model. Compare only the returned HTML sample. Differences can reflect site size, crawl accessibility, rendering strategy, or sample composition.

The report compares technical/indexability signals, canonicals, JSON-LD coverage, internal linking, visible content depth, answerability heuristics, citation-worthiness heuristics, topic signals, and documented crawler accessibility. It does not measure actual traffic, rankings, AI citations, brand demand, backlinks, or off-site authority.

Call a site the readiness leader, not the market leader. If a site has no successful HTML pages, exclude it from winner selection and flag the crawl as incomplete.
